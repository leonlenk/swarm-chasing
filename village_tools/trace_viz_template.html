Idea Spread Viewer

Follow one belief, norm or coined term as it moves through a group of AI agents: who said it first, who was exposed, who took it up, who pushed back, and how long it stayed in memory. Pick a bundled trace or open your own trace file.

Or drop JSON files anywhere on the page. Opened files are checked against format v0 and stay in this tab only; nothing is uploaded or saved.

    Trace format

    A trace is one JSON object about one idea in one group of agents. Times are ISO 8601 in UTC. Every list may be empty, and the viewer draws whatever is present: a coined-term trace with no exposures or edges still gets a timeline and curves. Agent names in every list must match agents[].name exactly. To bundle several traces, put them in one folder with an index.json that lists them.

    The full rules are in the JSON Schema at village_tools/swarmtrace/trace.schema.json.

    FieldWhat to put there
    version, id, title0; a short id (used in the page address, for example #hostility); a display title.
    kindbelief, norm or term. Used only to group the picker.
    statement, sourceThe idea in one sentence, and where the data came from and how it was labelled.
    start, endThe time window to draw.
    agents[]name, lab (Anthropic, OpenAI and Google get their own colours; any other lab is grey), group (any label, or null), joined and left (or null).
    events[]One per labelled message or action: id, t, agent, channel (chat, memory, session, search, summary), stance (originates, endorses, acts_on, mentions, uses, questions, rejects, mutates), conf (1–3 or null), room, snippet.
    exposures[]When an agent could have seen the idea: t, agent, source (agent or null), via (room, named, search, other), event (the event id seen, or null).
    adoptions[]When each agent took the idea up: agent, t, event, independent (true if no prior exposure explains it), sources (agent names).
    edges[]Agent-to-agent links: from, to, t, kind (transmission, echo, tip, correction), evidence.
    persistence[]Intervals when the idea sat in an agent’s saved memory: agent, start, end, where.
    annotations[]Context markers: t, label, kind (goal, intervention, scaffolding, artifact, note).
    quotes[]Wording over time: t, agent, text, note.
    metricsAny {name: number or text} pairs; each becomes a tile under the title.

    How to read it
    
    
      
      
    • Stance colours. Warm means for the idea (dark red: originates, red: endorses, amber: acts on it). Grey is neutral (mentions, uses). Cool means against it (lavender: questions, violet: rejects). A star is a mutation, whatever the channel. Lab colours appear only in row chips and network nodes, never in stance marks.
      • 
      
    • Channel shapes. Circle: chat. Square: saved memory. Triangle: session action. Diamond: history search. Ring: summary.
      • 
      
    • Labels are model-assigned. Stances, exposures, adoptions and edges come from the trace producer, usually an LLM labeller with a confidence of 1 (weak) to 3 (clear). Confidence 1 and auto-detected events with no label (confidence null) are drawn faded. Read the snippets before trusting a pattern, and check the source note for hand-check rates.
      • 
      
    • States in the network. Unexposed until the first exposure, or the first event when a trace has no exposure data. Adopted from the agent’s adoption (or an originates event). Rejecting while the agent’s latest for-or-against event is a rejection. If a trace lists no adoptions, the first warm event counts as adoption. The counters count agents who have ever reached each state.
      • 
      
    • Rows and exposure. Rows are grouped by role: the trace’s own group label when it has one, otherwise derived (origin if the agent has an originates event, adopter if it adopted, exposed if it was exposed or active, other). Grey shading is the number of exposures in each week (Monday to Sunday, UTC); darker means more. The tick marks the first exposure.
      • 
      
    • Adoption rings. A solid ring marks an adoption that follows exposure; a dashed ring marks one the producer judged independent.
      • 
      
    • Edges. Solid: transmission. Dotted: phrase echo. Dashed: tip. Violet: correction. A small dot marks the receiving end. Edges are the producer’s claims, not observed causation.
      • 
      
    • Network views. “Who passed it on” draws only agents with a link or an adoption, placed left to right by adoption time (or first link) and spread by a force layout with a fixed seed. “Who could have heard it” puts every agent on a ring by lab and first activity. Both draw the same way every time for the same trace. Times are UTC.
