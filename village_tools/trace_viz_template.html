Swarm trace viewer · format v0

Idea Spread Viewer

Follow one belief, norm or coined term as it moves through a group of AI agents: who said it first, who was exposed, who took it up, who pushed back, and how long it stayed in saved memory. Pick a bundled trace or open your own trace file.

Or drop JSON files anywhere on the page. Opened files are checked against format v0 and stay in this tab only; nothing is uploaded or saved.

    2Trace format

    A trace is one JSON object about one idea in one group of agents. Times are ISO 8601 in UTC. Every list may be empty, and the viewer draws whatever is present: a coined-term trace with no exposures or links still gets a timeline and running totals. Agent names in every list must match agents[].name exactly. To bundle several traces, put them in one folder with an index.json that lists them.

    The full rules are in the JSON Schema at village_tools/swarmtrace/trace.schema.json.

    Table: Fields of a v0 trace.
    FieldWhat to put there
    version, id, title0; a short id (used in the page address, for example #hostility); a display title.
    kindbelief, norm or term. Used only to group the picker.
    statement, sourceThe idea in one sentence, and where the data came from and how it was labelled.
    start, endThe time window to draw.
    agents[]name, lab, group (any label, or null), joined and left (or null).
    events[]One per labelled message or action: id, t, agent, channel (chat, memory, session, search, summary), stance (originates, endorses, acts_on, mentions, uses, questions, rejects, mutates), conf (1–3 or null), room, snippet.
    exposures[]When an agent could have seen the idea: t, agent, source (agent or null), via (room, named, search, other), event (the event id seen, or null).
    adoptions[]When each agent took the idea up: agent, t, event, independent (true if no prior exposure explains it), sources (agent names).
    edges[]Agent-to-agent links: from, to, t, kind (transmission, echo, tip, correction), evidence.
    persistence[]Intervals when the idea sat in an agent’s saved memory: agent, start, end, where.
    annotations[]Context markers: t, label, kind (goal, intervention, scaffolding, artifact, note).
    quotes[]Wording over time: t, agent, text, note.
    metricsAny {name: number or text} pairs; they become the trace’s key-numbers table.
     
    
    
    Build the page
    
    
    python village_tools/build_trace_viz.py [TRACE_FILES_OR_DIRS ...] -o OUT.html [--day-one YYYY-MM-DD]
    
    
    With no arguments it reads out/sprint_idea/traces/ (its index.json, or every *.json there), writes out/sprint_idea/idea_spread.html, and numbers AI Village days from day 1 = 2 April 2025 (Pacific time). Files that fail the check are reported and skipped.
    
  
    

  
    
    
    3How to read it
    
    
      
      
    • Stance has three classes. For the idea (originates, endorses, acts on it, uses it): a filled vermillion marker. Neutral (mentions, questions): a filled light-grey marker. Against (rejects): a hollow blue marker. A star is a reworded version of the idea (mutates), whatever the channel. In black-and-white print these read as dark, light and hollow.
      • 
      
    • Channel is the marker shape: circle, chat; square, saved memory; triangle, session action; diamond, history search; cross, summary.
      • 
      
    • Labels are model-assigned. Stances, exposures, adoptions and links come from the trace producer, usually an LLM labeller with a confidence of 1 (weak) to 3 (clear). Confidence 1 and auto-detected events with no label (confidence null) are drawn faded. Read the snippets before trusting a pattern, and check the source note for hand-check rates.
      • 
      
    • Rows are grouped by role: the trace’s own group label when it has one, otherwise derived (origin if the agent has an originates event, adopter if it adopted, exposed if it was exposed or active, other). The faint line through a row runs from when the agent joined to when it left.
      • 
      
    • Exposure and memory. Grey shading behind a row is the number of exposures in each week (Monday to Sunday, UTC); darker means more. The short vertical tick marks the first exposure. The thin grey line along the bottom of a row is the time the idea sat in the agent’s saved memory.
      • 
      
    • Adoptions are rings: solid when the adoption follows exposure, dashed when the producer judged it independent. If a trace lists no adoptions, the first “for” event counts as adoption in the running totals.
      • 
      
    • Links are the producer’s claims, not observed causation. Solid grey: transmission. Dotted: phrase echo. Dashed: tip. Blue: correction. A small dot marks the receiving end. Hover a row to see only that agent’s links.
      • 
      
    • Annotations other than goals are numbered markers; the key is listed under the swimlane. Goals are the light band along the top. Times are UTC; “Day N” is the Village day when the page was built with a day-one date.
      •
